REST API Integration Guide
Service: AI Data Utility APIPurpose: Provide simple REST APIs that allow an AI Agent or external systems to retrieve current time, current date, date-time information, and a list content pages from published materials.
The Base URL will depend on the deployment environment.
Example:
https://stonecurators-backend.com:3000/api/aiData/gettime

3. API Details

Endpoint

3.4 Get content pages from published materials
Endpoint
GET /aiData/get-material-content-pages
Description
Returns a list of content pages from published materials that are marked as published in the system.
This API is designed to allow AI agents or external applications to:
search for content pages from published materials
display available content pages from published materials
support chatbot product search functionality
Only material content pages with the following condition will be returned:
published = true
Authentication
This endpoint requires API Key authentication.
The API key is validated using:
authController.validateKey()
The key should be included in the request header.
Example Header
x-api-key: a7f3e2c1d8b4f6a9e5c3d8b1f0a4e7c2
Example Request
GET https://stonecurators-backend.com:3000/api/aiData/get-material-content-pages
Headers
x-api-key: a7f3e2c1d8b4f6a9e5c3d8b1f0a4e7c2
